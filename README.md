# Set up 

1. Clone the repo:
```bash
git clone git@github.com:nramirez-f/nramirez-f.github.io.git
```
2. Install your favourite JS package manager, pnpm in mi case:
```bash
pnpm install
```
> Note: is neccesary have pnpm intalled

3. Init the developer server:
```bash
pnpm run dev
```
